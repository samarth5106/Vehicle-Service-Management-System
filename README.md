# Vehicle Service Management System

DBMS mini-project using Next.js + Flask + MySQL.

## Architecture
Next.js UI -> Flask REST API -> custom SQL query engine -> mysql-connector-python -> MySQL.

No ORM or query-builder library is used. CREATE, INSERT, SELECT and UPDATE SQL are generated by our own Python code.

## Backend setup
1. `cd backend`
2. `python -m venv venv`
3. `venv\Scripts\Activate.ps1`
4. `pip install -r requirements.txt`
5. Copy `.env.example` to `.env` and set your MySQL root password.
6. `python -m db.schema_builder`
7. `python app.py`

API runs at `http://127.0.0.1:5000`.

## Frontend setup
1. `cd vehicle-service-management-frontend`
2. `pnpm install`
3. `pnpm dev`

Frontend runs at `http://localhost:3000`.

## Database entities
Customer, Vehicle, Mechanic, ServiceRecord, Parts, ServiceParts, Invoice.

See `docs/REPORT.md` for the DBMS report outline and viva notes.
